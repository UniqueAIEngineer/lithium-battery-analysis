# リチウムイオン電池 劣化判定ツール v6

内部抵抗（Re・Rct）の測定値から、リチウムイオン電池が劣化しているか（SOH 80% 未満か）を判定するツールです。容量は使いません。

## なぜ内部抵抗か

容量を正確に測るには、満充電から空になるまで放電させる必要がある。
何時間もかかるし、使っている途中の電池ではできない

内部抵抗は短時間で、電池を使い切らずに測れる

## データ

- NASA の Li-ion 電池劣化試験データ（Kaggle：patrickfleith/nasa-battery-dataset）
- 24℃ で試験された8本（B0005・06・07・18・25・26・27・28）を使用
- 内部抵抗の測定ごとに、同じ電池の直前の放電容量を組にした（12時間以上離れた組は除外）。942件
- SOH ＝ 放電容量 ÷ 定格 2Ah。0.8 未満を「劣化」とした
- B0026 の 2009-02-18 の放電1回（SOH 0.69）は、前後が 0.90 なのに1回だけ下がってすぐ戻っていたため、測定の誤りとして除いた
- データはこのリポジトリに含めていません。上の Kaggle のページから取得し、`data/` に置いてください

## 方法

- **Re_ratio** ＝ 今の Re ÷ その電池の最初の Re
- 電池により元々のReが違う。なので割合で見た方が比較しやすいため。
- 同じ SOH 0.9 でも、Re は電池によって 0.04〜0.10 と2倍以上違った

- 入力：Re_ratio と Rct。モデル：ランダムフォレスト（木100本）
- 検証：1本を試験用にして残り7本で学習し、試験用の電池で見逃し・言いすぎを数える。これを8本すべてで行った（初めて見る電池に通じるかを確かめるため）

## 結果

| 方法 | 見逃し | 言いすぎ |
| --- | --- | --- |
| 線1本（Re_ratio が 0.986 以上で劣化） | 22 | 229 |
| 線1本（Re の値そのまま） | 5 | 177 |
| ランダムフォレスト（確率 0.5 以上で劣化） | 54 | 40 |
| **ランダムフォレスト（確率 0.2 以上で劣化）** ← 採用 | **15** | **105** |

劣化の見逃しを重く見た。電池の劣化を見逃すと、急に止まる・発熱などの危険があるため。
そこで確率の線を 0.5・0.3・0.2 と変えて比べ、0.2 を採用した。0.2 なら線1本より
見逃しも言いすぎも少なかった。

## 限界

- 使った電池は8本だけで、劣化したのはそのうち4本
- B0018 は内部抵抗がほとんど上がらないうちに劣化したため、見逃しが残った（12件）
- 確率の線 0.2 や、外れ値の扱いは8本すべてを見て決めたため、本当に新しい電池では性能がこれより下がる可能性がある
- 最初の Re を1回の測定で決めているため、その1回がずれると倍率もずれる
- 24℃ のデータだけで学習した。ほかの温度では確かめていない
